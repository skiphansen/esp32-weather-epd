# ESP32 E-Paper Weather Display

This is my fork of Lmarzen's excellent [esp32-weather-epd](https://github.com/lmarzen/esp32-weather-epd.git) project which adds
support for Waveshare's [photo painter](https://www.waveshare.com/esp32-s3-photopainter.htm?srsltid=AfmBOopGRjpLEdUNAb3sJkpIs5su8KLOEsnrZXuGoSHAuC9ghYpRJnmZ). 

I'm not sure I'd spend the $$$ for a photo painter just for this project but I had one.  Since the Photo painter is available off the shelf and is complete
including a frame perhaps it's worth it for someone that doesn't have the time or interest to build a display.

I am currently working on another project using a [Seeed Studio ee04](https://wiki.seeedstudio.com/epaper_ee04/) controller with a 7.4" BWRY EPD which would be a cheaper alternative. 
 
I was going to send a [PR](https://github.com/lmarzen/esp32-weather-epd/issues/235) to Lmarzen 
but I since I ended up returning my Photo painter for a refund so I can no longer support the port.

I ran this code for a couple of weeks before I returned the photo printer and
other than hardware issue https://github.com/skiphansen/esp32-weather-epd/issues/1 I ran
into it worked well.

I understand that the problem has been fixed in V2.
