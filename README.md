# ESP32 E-Paper Weather Display

This is my fork of lmarzen's excellent [esp32-weather-epd](https://github.com/lmarzen/esp32-weather-epd.git) project which adds
support for  [Waveshare's photo painter](https://www.waveshare.com/esp32-s3-photopainter.htm?srsltid=AfmBOopGRjpLEdUNAb3sJkpIs5su8KLOEsnrZXuGoSHAuC9ghYpRJnmZ). 

I'm not sure I'd spend the $$$ for the the photo painter just for this project but the photo printer is off the shelf including a frame and I had one.

I am currently working on another project using a [Seeed Studio ee04](https://wiki.seeedstudio.com/epaper_ee04/) controller with a 7.4" BWRY EPD which would be a cheaper alternative. 
 
I was going to send a [PR](https://github.com/lmarzen/esp32-weather-epd/issues/235) to lmarzen 
but do to an [issue](https://github.com/skiphansen/esp32-weather-epd/issues/1) with my V1.0 photo printer
I ended up returning it for a refund so I can no longer support the port.

I ran the port for a couple of weeks before I returned the photo printer and
other than issue https://github.com/skiphansen/esp32-weather-epd/issues/1 it worked
well.
